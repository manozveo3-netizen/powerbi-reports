# Sample Power BI Report

This folder contains `sample_report.pbix`, a Microsoft Power BI Desktop report file.

## Open the report

1. Install the latest [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Download `sample_report.pbix`.
3. Open it in Power BI Desktop.

## Refresh data

In Power BI Desktop, select **Home → Refresh**. If Power BI requests credentials or a source location, provide access to the report's original data source, then select **Transform data** to review the queries if needed.

## Customize

- **Data model:** Use Model view to review tables and relationships.
- **Visuals:** Select a visual to adjust fields, filters, formatting, or interactions.
- **Measures:** Create or update DAX measures from the Modeling tab.
- **Publish:** When ready, select **Publish** to upload the report to the appropriate Power BI workspace.

## Notes

- Keep source credentials private; do not share them inside the `.pbix` file or this README.
- Confirm that all report data is current before sharing or publishing.
- Use a descriptive version name when distributing updated report files.

## Requirements

- Microsoft Power BI Desktop
- Access to the report's data source(s), if a refresh is required
